# VentilaLab

Módulo integral de prática individual extraído do VentilaLab original. Três casos, treino livre, VCV, PCV, curvas, controles, avaliações e alertas preservados. Os hashes e testes registram o núcleo importado.

Entrada: `/simulators/ventilacao-mecanica/index.html`. Rota da plataforma: `/ventilacao-mecanica`.

Aulas, slides, sessão sincronizada e exportação de notas em PDF ficam somente no projeto original, conforme solicitado. O simulador não precisa dessas funções, backend, login ou API. `fonts.css` substitui exclusivamente `next/font` usando os arquivos locais originais.
