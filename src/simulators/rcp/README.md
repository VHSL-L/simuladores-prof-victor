# Simulador de RCP

O simulador é mantido como módulo isolado para preservar sua lógica, seus estilos e seu comportamento.

- Origem preservada: `megacode-prof-victor-sequencial.html`
- Cópia executável: `public/simulators/rcp/index.html`
- Integração: a rota `/rcp` carrega a cópia local em um frame de mesma origem com altura responsiva.
- APIs externas: nenhuma.
- Armazenamento, autenticação, banco de dados, áudio e timers: não utilizados nesta versão.

Não altere o conteúdo clínico dentro da cópia sem revisão explícita do autor.
