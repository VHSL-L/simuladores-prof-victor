# Sala de Choque

Cópia integral de `app/page.tsx`, `app/globals.css` e `app/crt.css` do projeto original `simulador-choque`. Cinco casos, estados, escolhas, efeitos e feedbacks preservados. `main.tsx` substitui apenas o invólucro Next/vinext por React/Vite.

Entrada: `/simulators/choque/index.html`. Rota da plataforma: `/choque`.

Progresso na sessão do navegador (`sala-de-choque-progress`). Sem API, imagens ou sons; fontes Google Fonts como no original. Consulte `MIGRATION.md` para limitações preexistentes.
